# STEP-SEM3 Week 2 Assignment — Solved

Solutions for the five problems in `STEP-SEM3-Week2-Assignment Problems.pdf`.

1. **ATM PIN Length Validator** — checks that the PIN string length is exactly 4, using a single if/else as requested.
2. **Word Reversal Encoder** — reverses each word individually and keeps word order.
3. **Product Inventory CSV Parser** — splits CSV, validates exactly three fields, and prints a formatted record.
4. **Library ISBN Normalizer & Validator** — trims spaces, uppercases only the first three characters, validates length/letters/digits without regex, and formats the result.
5. **Stop-Word-Filtered Word Frequency Report** — lowercases, strips common punctuation, excludes the specified stop words, counts words, and sorts by descending frequency.

## Compile and run
Use Java 8 or later. From `src`, compile and run each program separately. Example:

```bash
javac Problem1ATMPinLengthValidator.java
java Problem1ATMPinLengthValidator
```
